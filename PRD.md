## Accenture Advanced Technology Engineer (ATE) Internship Assessment Simulator

**Document Version:** 2.0.0  
**Target Profile:** Advanced Technology Engineer (ATE) - 2-Month Summer Internship  
**Target Batch:** 2027 Pass-out Batch (3rd Year B.Tech / M.Tech / MCA / Dual Degree)  
**Stipend:** ₹60,000 / Month (₹1,20,000 Total 2-Month Compensation + Pre-Placement Offer (PPO))  
**Status:** Approved for Implementation  

---

## 1. Product Vision & Value Proposition

### 1.1 The Opportunity & Stakes
Accenture India conducts specialized on-campus and national recruitment for the **Advanced Technology Engineer (ATE) Internship** offering **₹60,000 / month stipend** and direct **Pre-Placement Offer (PPO)** conversion.

Because this is a premium tier role with massive student competition across top institutions (NITs, IITs, top state/private universities), the evaluation bar is substantially higher than standard bulk hiring.

### 1.2 Official Selection Procedure (Derived from Official Campus JNF)
The official assessment structure consists of:
1. **On Campus Assessment:**
   - **Cognitive Assessment** (English Ability, Critical Thinking, Abstract Reasoning)
   - **Behavioral Assessment** (Situational Judgement, Leadership, Agile & Collaborative Profiling)
   - **Technical Assessment** (Pseudocode, Common Applications, Cloud & Network Security)
   - **Coding Assessment** (2 Algorithmic DSA Problems in 45 Minutes)
2. **Virtual Evaluation:**
   - **Communication Assessment** (AI Spoken English / Versant Format)
   - **Personal Interviews** (Up to 4 Rounds: Technical Architecture, Problem Solving, Core CS Fundamentals & HR Behavioral)

### 1.3 The Solution
An authentic, all-in-one preparation and assessment simulator specifically tailored to crack every stage of this ₹60,000/month ATE internship drive.

## 2. Target Personas & Commercial Value

### 2.1 Personas
- **P1: 3rd-Year B.Tech Student (2027 Batch):** Target on-campus Accenture ATE internship drive. Needs to master higher-difficulty DSA coding, advanced pseudocode, and psychometric behavioral questions.
- **P2: Non-CS / ECE / Mechanical / Civil Student in Eligible Pool:** Eligible for ATE under the "All Branches" policy; needs fast-track mastery of core CS, networking, and cloud fundamentals.

### 2.2 Student ROI & Pricing Model
- **Pricing:** ₹500 one-time fee for the **Accenture ATE Internship Mastery Pass**.
- **Value ROI:** Unlocks the gateway to a ₹1,20,000 summer stipend + guaranteed PPO track before entering final year.

## 3. Core Modules & Feature Scope

### 3.1 Module 1: Cognitive & Behavioral Assessment Engine
- **Cognitive:**
  - 17 English Ability questions (sentence correction, reading passages, cloze test).
  - 18 Critical Thinking questions (syllogisms, 8-person circular seating, direction sense, data sufficiency).
  - 15 Abstract Reasoning questions (visual series, pattern matrices, spatial folding).
- **Behavioral & Situational Judgement (New ATE Requirement):**
  - Scenario-based workplace dilemmas evaluating Accenture core values: Client Centricity, Collaborative Mindset, Agile Decision Making, and Ethical Ownership.
  - Interactive ranking of actions: "Most Effective" vs "Least Effective".

### 3.2 Module 2: Technical & Pseudocode Tracing
- **Pseudocode (18 Questions):** Bitwise manipulation (`^`, `&`, `|`, `~`, `<<`, `>>`), recursive call stacks, pre/post-increment loop side effects, pointer arithmetic.
- **Common Applications & MS Office (12 Questions):** Excel formulas (`VLOOKUP`, `INDEX-MATCH`, `SUMIF`), Word formatting, PowerPoint presentation shortcuts, browser caching/cookies.
- **Network Security & Cloud (10 Questions):** OSI 7 layers, TCP vs UDP, port mappings, symmetric/asymmetric encryption, cloud service architectures (IaaS, PaaS, SaaS).

### 3.3 Module 3: Advanced Coding IDE (45 Mins, 2 Problems)
- **Problem Distribution:**
  - Problem 1: String & Array manipulation / Number theory (Easy-Medium).
  - Problem 2: Algorithmic optimization (Two-pointer, greedy, sliding window, dynamic programming basics).
- **Compiler Sandbox:**
  - Supports Python 3, Java, C++, and C#.
  - Execution against public sample test cases (with diff visualizer).
  - Private evaluation against hidden edge cases (negative numbers, large bounds $10^5$, memory constraints).

### 3.4 Module 4: Versant AI Spoken Communication Simulator
- 6 Interactive Audio Modules:
  - Reading Aloud (8 sentences).
  - Repeating Sentences (16 audio prompts).
  - Rapid Oral Q&A (20 factual questions).
  - Sentence Builds / Jumbled Sentences (10 audio prompts).
  - Story Retelling (3 narrative prompts).
  - Open Speaking Monologue (2 topics).

### 3.5 Module 5: Monetization & Paywall (₹500 Unlock)
- Instant account creation (Email + Password / Google OAuth).
- Free Tier: Day 1 Diagnostic Mock Exam + 2 Coding Problems.
- Pro Unlock Modal (₹500): Razorpay / Stripe checkout (UPI, Cards, Netbanking).
- Instant webhook signature validation unlocking all 30 days of the ATE curriculum.
